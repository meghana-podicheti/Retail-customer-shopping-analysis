This project analyzes customer shopping behavior to identify trends, customer segments, and revenue patterns.

## 🔍 Key Insights

- Female customers generate higher total revenue than male customers  
- Customers using discounts still show strong purchasing behavior  
- Express shipping users spend more per transaction  
- Loyal customers contribute significantly to revenue  
- Seasonal trends impact customer purchasing behavior
